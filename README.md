# tuikit

The look and the keys shared by my terminal apps (eardrill, rdtui, sonetui), so they behave the
same: the Nord-based palette and named styles, nvim-notation keymaps overridable from a TOML
config, the four-row chrome (tabline, body, statusline, command line), and a few widgets.

```toml
[dependencies]
tuikit = { git = "https://github.com/cammellos/tuikit" }
```

See the module docs in `src/lib.rs`.
